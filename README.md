## 📌 About This Repository

This repository is a structured, continuously growing record of my Python practice — built exercise by exercise to strengthen programming fundamentals, logical thinking, and problem-solving ability, with a long-term focus on data analysis and machine learning workflows.

Each notebook targets a specific set of concepts and contains two question formats:

- 🖊️ **Code Writing** — solve a stated problem from scratch
